## What I Learned

Melalui project ini, kami mempelajari dasar-dasar kolaborasi dalam pengembangan project menggunakan Git dan GitHub. Kami juga belajar menggunakan branch, melakukan commit dan push, membuat Pull Request, melakukan code review, serta menggabungkan perubahan ke branch utama.

Selain itu, kami memahami pentingnya pembagian tugas dan komunikasi antar anggota ketika beberapa bagian project saling berhubungan.
